# V-GEN 제주 VPP 수익 계산기

제주 입찰시장 운영기준에 따라 급전가능재생에너지 CP 용량정산금과 계약 배분액을 계산하는 Streamlit 앱입니다.

## 핵심 산식

`CP 수익 = 설비용량(kW) × 8,760시간 × 실효용량비율 × 적용 CP 단가(원/kWh) × RPCF`

- 2026/27 제주 태양광 실효용량비율 공식 평균: 5.20%
- 2026/27 제주 공식 RCP: 22.05원/kWh
- 요청 시나리오 CP 단가: 14원/kWh
- IMBP 차감 후 50:50 배분
- 영업채널 수수료: 브이젠 배분액의 20%
- RTU 및 신자취: 각 150만원, 발전사업주 부담

RPCF, IMBP와 기타정산은 자원별 실제 값에 맞게 직접 수정할 수 있습니다.
