# V-GEN 재생에너지 입찰시장 수익 계산기

기본 전력·REC 수익과 입찰시장 추가수익을 분리해 계산하는 Streamlit 앱입니다.

## 기본 육지 태양광 기준

- 실효용량비율 12.78%
- CP 단가 14원/kWh
- RPCF 100% (육지 중립 가정)
- MWP 50만원/MW·년
- MAP 50만원/MW·년
- IMBP 80만원/MW·년
- 배분대상 추가수익 약 1,587만원/MW·년

2026년 1차 제주 RPCF 결과에서 순수 태양광 16개 자원의 평균은 105.08%, 중앙값은 106.33%였습니다. 육지 기본값 100%는 확정값이 아닌 중립적인 사업성 가정이며 직접 수정할 수 있습니다.

## 계약 구조

- `추가수익 = CP + MWP + MAP - IMBP`
- SMP/PPA+REC 기본수익은 추가수익 배분에서 제외
- IMBP 차감 후 50:50 배분
- 영업채널 수수료는 브이젠 배분액의 20%
- RTU·신자취는 각 150만원, 발전사업주 부담

모든 주요 가정은 화면에서 직접 수정할 수 있습니다.
