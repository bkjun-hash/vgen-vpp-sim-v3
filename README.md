# V-GEN VPP 수익 계산기

재생에너지 입찰시장 영업 검토용 간편 Streamlit 계산기입니다.

## 반영 사항

- 기본 1MW 총 추가수익 1,400만원, IMBP 100만원 차감
- IMBP 차감 후 발전사업주·브이젠 50:50 배분(각 650만원)
- 영업채널 계약 시 브이젠 몫의 20% 지급
- RTU와 신자취 각각 150만원을 발전사업주 부담으로 반영
- 용량, CP 계수, RPCF를 첫 화면에서 직접 수정
- 용량별 비교와 Excel 다운로드

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

실제 전력시장 정산은 거래시간별 자료를 사용합니다. 본 계산기는 연간 등가 영업 시뮬레이션이며 실제 정산서를 대체하지 않습니다.
